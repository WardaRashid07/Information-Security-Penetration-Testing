## Section 1: Capture Methodology

**Interface Selected:** eth0 (Kali's primary network interface)

**Reason:** eth0 is the only interface connected to the NAT network where target VMs (Windows XP at 192.168.32.138 and Metasploitable 2 at 192.168.32.139) reside.

**Traffic Generation Method:**
- **ICMP:** `ping -c 20 192.168.32.139` generated echo request/reply pairs
- **HTTP:** `curl -v http://192.168.32.139/` generated GET request and response
- **FTP:** `ftp 192.168.32.139` with msfadmin/msfadmin credentials generated authentication traffic

**Capture Tool:** tcpdump with protocol-specific filters:
- ICMP: `tcpdump -i eth0 icmp -w icmp.pcap`
- HTTP: `tcpdump -i eth0 tcp port 80 -w http.pcap`
- FTP: `tcpdump -i eth0 'tcp port 21 or tcp port 20' -w ftp.pcap`

## Section 3: Security Observations

### Finding 1 - Plaintext FTP Credentials (Critical)
- **Packet numbers:** USER msfadmin, PASS msfadmin
- **Risk:** Any attacker with network access can capture login credentials using Wireshark/tcpdump
- **Evidence screenshot:** wireshark_ftp_filter_F2023332043.png

### Finding 2 - Server Version Disclosure (Medium)
- **Information disclosed:** Apache/2.2.8 (Ubuntu) DAV/2, PHP/5.2.4
- **Risk:** Attackers can search for known exploits against these specific versions
- **Evidence:** Nikto scan confirmed outdated software

### Finding 3 - No ICMP Flood Detection (Informational)
- **Observation:** All ICMP packets were normal size (frame.len = 98 bytes)
- **No large ICMP packets (>100 bytes)** detected in the capture
- **Risk:** IDS rules for `icmp && frame.len > 100` would not trigger
- **Evidence:** Screenshot 30_wireshark_ids_icmp_F2023332043.png shows empty result

## Section 4: Recommendations

### For FTP Protocol
| Recommendation | Priority |
|----------------|----------|
| Replace FTP with SFTP (SSH File Transfer Protocol) or FTPS | HIGH |
| Use strong authentication mechanisms (key-based instead of password) | HIGH |
| Implement network segmentation to limit FTP traffic | MEDIUM |

### For HTTP Protocol
| Recommendation | Priority |
|----------------|----------|
| Enable HTTPS with valid TLS certificate for all web traffic | HIGH |
| Remove server version headers to reduce information disclosure | MEDIUM |
| Regularly update web server and PHP to latest versions | HIGH |

### For ICMP Protocol
| Recommendation | Priority |
|----------------|----------|
| Rate-limit ICMP traffic to prevent ping floods | MEDIUM |
| Monitor for ICMP packets with unusual payload sizes (>100 bytes) | LOW |

### General Infrastructure Recommendations
1. Enable encryption for all protocols (FTP→SFTP, HTTP→HTTPS)
2. Implement IDS/IPS rules to detect plaintext credentials and large ICMP packets
3. Regular vulnerability scanning with Nessus/Nikto
4. Apply security patches to Metasploitable (Apache, PHP, vsftpd)
5. Disable unnecessary services
